
# 🚀 PowerEthiopia Admin Dashboard

This is a **Next.js 15** project that manages **training program registrations**. It’s built with modern technologies like **TypeScript**, **Tailwind CSS**, **Framer Motion**, and **React Table**, providing a fast, interactive, and responsive admin experience.

---

## 🛠 Features

* Display a list of registered users with **pagination** and **search-ready columns**.
* Manage user actions: **View, Edit, Download, Delete** (coming soon).
* Fully responsive for **desktop and mobile**.
* **Dark & Light mode** compatible.
* Animations powered by **Framer Motion**.
* Interactive badges showing **shift, training time, and status**.
* Modular architecture for **clean code and easy maintenance**.

---

## 📦 Tech Stack

* [Next.js 13](https://nextjs.org) (App Router & Server Components)
* [TypeScript](https://www.typescriptlang.org/)
* [Tailwind CSS](https://tailwindcss.com/)
* [Framer Motion](https://www.framer.com/motion/)
* [React Table](https://tanstack.com/table/v8)
* [Tabler Icons](https://tabler-icons.io/)
* [Sonner Toasts](https://sonner.toast.com/)
* MongoDB / API integration (via your backend)

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Ethiosolar/PowerEthiopia.git
cd PowerEthiopia
```

### Install dependencies

```bash
npm install
# or
yarn
# or
pnpm install
```

### Run the development server

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

The page auto-updates as you edit the code.
